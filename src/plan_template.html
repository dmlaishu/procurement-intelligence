How each date is calculated and what is not known

Likely award. A model trained on {{N_TRAIN}} tenders opened before {{SPLIT}} predicts the day by which half of tenders like yours are awarded. It was then tested on {{N_TEST}} tenders opened after that date, which it had never seen.

Plan for. A second, conservative model aims for a date by which about 80 in 100 similar tenders are awarded. In testing it covered {{COV}} in 100. This is the date to put in a plan.

Delivery. Illustrative only: the plan-for date plus the usual contracted delivery period from award notices. Actual delivery dates are not published, so it is not a validated prediction.
