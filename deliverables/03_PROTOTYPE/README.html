Deliverable 3: Prototype

A working, end-to-end prototype of the Procurement Intelligence Platform for medical laboratory and diagnostic equipment in World Bank-financed health projects, on real public World Bank data from 91 countries. It includes a chatbot that answers questions with cited evidence.

What is in this folder

File What it is
prototype_report.html results page: data coverage, knowledge graph, models, retrieval, guardrails, an example brief
demo_brief.md the copilot's brief for a new PCR / GeneXpert package (every line cited)
eval_results.json every measured number used in the report and approach, including the chatbot evaluation
prototype_source.zip source code: pipeline and chatbot (procurement_demo/), Databricks notebooks 20-29, tests, build scripts

The chatbot

python -m streamlit run procurement_demo/app.py

Ask in plain English, for example:

  • Which supplier won the cheapest GeneXpert or PCR contract? → exact ranking over contract awards
  • Who are the top suppliers of diagnostic imaging equipment in Sub-Saharan Africa? → supplier market shares
  • How much was spent on laboratory equipment by country? → spend breakdown
  • How long does it take to award a laboratory analyzer tender? → censoring-aware benchmarks
  • What problems did projects have with laboratory equipment maintenance? → lessons and report passages, with pages
  • Show the entity relationship diagram / How is Kenya connected to its lab equipment suppliers? → graph diagrams

Each answer shows its evidence (contract rows, benchmarks, report pages with links), the result table, and any sentence the verifier removed. On 16 labelled questions it chose the right tool for 100% and matched an independent query in 6 of 6 exactness checks. Optional: pip install anthropic, set credentials and PROC_CHAT_LLM=1 to have an LLM rephrase verified answers. Its text is discarded if it adds any number.

How to run it

Needs Python 3.11+. The first run downloads about 150 MB and parses about 130 PDFs (20-30 minutes); later runs reuse the cache.

  1. Unzip prototype_source.zip into an empty folder and open a terminal there.
  2. Install the packages:

bash pip install -r requirements_procurement.txt

  1. Check the shared library (it should end with ALL PASSED):

bash python src/test_proc_lib.py

  1. Build everything:

bash python -m procurement_demo.run_all

  1. Start the chatbot:

bash python -m streamlit run procurement_demo/app.py

Point it at another domain: the scope is one configuration block in procurement_demo/common.py. Set PROC_SCOPE=india_roads (PowerShell: $env:PROC_SCOPE = "india_roads") to run the same pipeline on Indian rural and inter-urban roads, or three_country for Kenya, Nigeria and Bangladesh across all sectors.
